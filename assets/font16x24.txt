# QDOS 16x24 bitmap font -- the source the firmware is built from.
#
# '#' is a lit pixel, '.' is unlit; the leftmost character is the leftmost
# pixel. One block per glyph: a `0xNN name` header, then exactly 24 rows of 16.
# tools/genfont.py packs this into src/ui/font16x24.c.
#
# The metrics the font keeps to, which tools/genfont.py checks:
#
#   cap height   rows 3 to 21        stem      3px
#   x-height     rows 7 to 21        body      columns 1 to 14
#   baseline     row 21              descent   none; only _ reaches row 22
#
# Codes 1 to 9 are symbols the panel needs that ASCII has no room for. They sit
# below space, so a label is still a plain C string.
